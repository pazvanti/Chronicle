## Technical Features

- **Mathematical Smoothness**: Zero CSS transition frame drops; all positions, 3D rotations, and opacities are mathematically computed using Hermite curves, Quintic easing, and spring physics inside a 60/120 FPS `requestAnimationFrame` loop.
- **Audio-Reactive Engine**: Downbeat detection triggers subtle rhythm pulses on the HUD indicator, particle surges, and equalizer cell illumination while keeping the camera rock-solid and cinematic.
- **Broadcast Telemetry HUD**: Includes SMPTE-style timecode (`TC 00:00:00:00`), live BPM meter, scene markers, and recording status.
- **Self-Contained**: All fonts (Cinzel, Outfit, Inter, JetBrains Mono, Newsreader) and audio tracks are bundled locally inside the project.
